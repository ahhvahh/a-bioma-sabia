## Premissa

Operações disponíveis aos usuários serão cadastradas previamente pelo operador pela interface administrativa local e persistidas no catálogo de ações.

## Motivo

A condição é necessária para a operação das capacidades dependentes na baseline atual.

## Evidência atual

Regra estabelecida do projeto.

## Risco se estiver incorreta

As capacidades dependentes podem não operar conforme os fluxos documentados.
