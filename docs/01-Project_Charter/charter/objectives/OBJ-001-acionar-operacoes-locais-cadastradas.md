# OBJ-001 — Permitir que usuários autorizados acionem operações locais previamente cadastradas por meio dos clientes Telegram do Sabiá.

![Status](https://img.shields.io/badge/Status-refinement-d4a72c?style=flat-square)
![Version](https://img.shields.io/badge/Version----6e7781?style=flat-square)

**Disposition:** active

## Objetivo

Permitir que usuários autorizados acionem operações locais previamente cadastradas por meio dos clientes Telegram do Sabiá.

## Motivação

Formalizar uma responsabilidade necessária ao propósito do Sabiá sem ampliar a fronteira além do Scope aprovado.

## Resultado esperado

Um comando permitido percorre Telegram → Sabiá → operação cadastrada → resposta pelo mesmo cliente e destino.

## Critérios verificáveis

- Um comando permitido percorre Telegram → Sabiá → operação cadastrada → resposta pelo mesmo cliente e destino.

## Limites

Este objetivo não autoriza responsabilidades além dos itens de escopo relacionados.

- Fluxos: FLW-001, FLW-007
